CAPÍTULO 01

Como a internet e os sites funcionam?

Quando abrimos um site, nosso navegador se comunica com computadores chamados servidores.

Esses servidores enviam arquivos e informações para que a página seja apresentada.

As partes principais

  • Frontend: aquilo que o usuário vê e utiliza.
  • Backend: sistema que executa regras no servidor.
  • API: interface para comunicação entre sistemas.
  • Banco de dados: armazena informações.
  • Domínio: endereço público do site.
  • Hospedagem: serviço que mantém o site acessível.
Domínio é endereço. Hospedagem disponibiliza a aplicação. API permite comunicação. Banco de dados armazena informações.

Exemplo de uma loja virtual

CLIENTE
   |
   v
SITE / FRONTEND
   |
   v
BACKEND / API
   |
   v
BANCO DE DADOS
   |
   v
RESPOSTA AO CLIENTE

Uma loja real também pode integrar sistemas de pagamento, estoque, transportadoras e notificações.

CAPÍTULO 02

HTML: a estrutura da página

HTML significa HyperText Markup Language. É a linguagem de marcação que organiza o conteúdo.

Estrutura básica

<!DOCTYPE html>
<html lang="pt-BR">

<head>
  <meta charset="UTF-8">
  <title>Meu Site</title>
</head>

<body>

  <!-- Eu apresento o título. -->
  <h1>Minha primeira página</h1>

  <!-- Eu apresento um parágrafo. -->
  <p>Estou aprendendo HTML.</p>

</body>
</html>

Tags importantes

TagFunção
<h1>Título principal
<p>Parágrafo
<a>Link
<img>Imagem
<button>Botão
<form>Formulário
<section>Seção
HTML não é uma linguagem de programação. É uma linguagem de marcação.
CAPÍTULO 03

CSS: o design profissional

CSS controla cores, tamanhos, espaçamentos, fontes, animações e responsividade.

Exemplo comentado

/* Eu defino o fundo da página. */
body {
  background: #0f172a;
  color: white;
  font-family: Arial, sans-serif;
}

/* Eu estilizo os botões. */
button {
  background: #2563eb;
  color: white;
  padding: 12px 20px;
  border: none;
  border-radius: 8px;
}

/* Eu adapto a página para celulares. */
@media (max-width: 600px) {
  button {
    width: 100%;
  }
}

O que é responsividade?

É a capacidade de uma página se adaptar a celulares, tablets e computadores.

Um site profissional precisa ser legível, navegável e acessível em diferentes telas.
CAPÍTULO 04

JavaScript: comportamento e interação

JavaScript permite reagir a cliques, manipular dados, validar formulários e conversar com APIs.

Variáveis

// Eu guardo o nome de um produto.
const nome = "Notebook";

// Eu guardo o preço.
const preco = 3500;

// Eu posso alterar uma quantidade.
let quantidade = 2;

// Eu calculo o total.
const total = preco * quantidade;

console.log(total);

Funções

// Eu crio uma função para calcular preços.
function calcularTotal(preco, quantidade) {
  return preco * quantidade;
}

// Eu executo minha função.
const resultado = calcularTotal(50, 3);

console.log(resultado); // 150

Eventos

// Eu encontro um botão existente na página.
const botao = document.getElementById("comprar");

// Eu executo uma ação quando ele é clicado.
botao.addEventListener("click", () => {
  alert("Produto adicionado!");
});
O exemplo do botão exige que exista um elemento com id="comprar" no HTML.
CAPÍTULO 05

React: construindo interfaces com componentes

React é uma biblioteca JavaScript utilizada para criar interfaces de usuário.

Na M.O Store utilizamos React com Vite, uma ferramenta que facilita o desenvolvimento e a geração dos arquivos de produção.

Um componente React

// Eu crio um componente chamado Saudacao.
function Saudacao() {

  // Eu retorno a interface do componente.
  return (
    <h1>Bem-vindo à minha loja!</h1>
  );
}

// Eu disponibilizo o componente.
export default Saudacao;

O que são props?

Props são informações passadas de um componente para outro. 

// Eu recebo o nome como propriedade.
function Produto({ nome }) {
  return <h2>{nome}</h2>;
}

// Eu utilizo o componente.
<Produto nome="Notebook" />

O que é useState?

import { useState } from "react";

function Contador() {

  // Eu armazeno o valor atual.
  const [numero, setNumero] = useState(0);

  return (
    <button
      onClick={() => setNumero(numero + 1)}
    >
      Cliques: {numero}
    </button>
  );
}
Esses exemplos são JSX para um projeto React. Não funcionam sozinhos dentro de um HTML comum no Koder sem a preparação adequada.

CAPÍTULO 07

APIs, JSON Server e fetch

Nossa M.O Store utiliza JSON Server para simular uma API de produtos.

Endereço local

http://localhost:3001/produtos

localhost representa o próprio dispositivo que está fazendo a requisição.

Buscando produtos

// Eu consulto a API.
const resposta = await fetch(
  "http://localhost:3001/produtos"
);

// Eu converto a resposta para JavaScript.
const produtos = await resposta.json();

Configuração centralizada

Na Aula 162, nossas páginas passaram a utilizar uma configuração central. 

// Arquivo: src/config/api.js

// Eu consulto a variável do Vite.
// Se não existir, utilizo a API local.
const enderecoConfigurado =
  import.meta.env.VITE_API_URL ||
  "http://localhost:3001";

// Eu removo barras finais desnecessárias.
export const API_URL =
  enderecoConfigurado.replace(/\/+$/, "");

Utilizando a configuração

// Eu importo o endereço da API.
import { API_URL } from "../config/api.js";

// Eu consulto o catálogo.
const resposta = await fetch(
  `${API_URL}/produtos`
);

Arquivo .env.example

VITE_API_URL=http://localhost:3001
Nunca coloque senhas ou chaves secretas em variáveis VITE_. Elas podem ficar visíveis no navegador.
CAPÍTULO 08

Carrinho, Context API e pagamento

Nossa M.O Store utiliza Context API para compartilhar informações do carrinho.

O que é Context API?

É um recurso do React que permite compartilhar dados entre componentes sem passar propriedades manualmente por muitos níveis.

Exemplo de cálculo

// Eu calculo o valor total de um item.
function calcularSubtotal(produto) {
  return produto.preco * produto.quantidade;
}

// Eu crio um produto de exemplo.
const produto = {
  preco: 100,
  quantidade: 3
};

console.log(calcularSubtotal(produto));
// Resultado: 300

Pagamento da M.O Store

Nosso projeto do SENAI possui um formulário de pagamento simulado.

  • Validação de campos com React Hook Form e Zod.
  • Estado de processamento.
  • Página de sucesso.
  • Página de falha.
  • Regra especial para cartão com 16 dígitos repetidos.
A M.O Store não cobra dinheiro real. Para isso, precisaríamos de backend, pedidos persistentes e integração segura com um provedor de pagamentos.

CAPÍTULO 10

Git, GitHub, branches e commits

Git controla as versões do projeto. GitHub permite armazenar e compartilhar repositórios pela internet.

Consultar a situação do projeto

git status

Verificar a raiz do repositório

git rev-parse --show-toplevel

Esse comando é importante para evitar trabalhar no repositório errado.

Criar uma branch

git switch -c feature/configuracao-api

Preparar arquivos específicos

git add .env.example src/config/api.js src/pages/Produtos.jsx src/pages/ProdutoDetalhes.jsx

Criar o commit

git commit -m "feat: centraliza configuracao da API para publicacao"

Enviar a branch

git push -u origin feature/configuracao-api

Voltar para develop

git switch develop

Integrar a funcionalidade

git merge feature/configuracao-api

Atualizar o GitHub

git push origin develop
Nosso commit da configuração da API recebeu o identificador fb73474.

Na Aula 174, enviamos a develop atualizada ao repositório privado do GitHub.

O que é fast-forward?

É uma integração em que o Git consegue avançar uma branch até o commit de outra, sem criar um commit de merge adicional.

ESLint, Vitest e build de produção

ESLint

Analisa o código para encontrar problemas e verificar regras de qualidade. 

npm run lint

Vitest

Executa testes automatizados das funções da nossa aplicação. 

npm test

  • 4 testes de cálculo do carrinho.

Build

npm run build

Esse comando utiliza o Vite para gerar os arquivos de produção dentro da pasta dist.

Domínio, hospedagem e o futuro full stack

GitHub já coloca o site no ar?

Não automaticamente. O GitHub guarda o código do projeto.

Para publicar, precisamos configurar um serviço como GitHub Pages, Vercel ou Netlify.

E a nossa API?

O JSON Server funciona localmente enquanto estamos desenvolvendo.

Para a loja funcionar na internet, precisamos de uma API acessível aos visitantes.
